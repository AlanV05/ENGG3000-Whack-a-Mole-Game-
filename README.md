# ENGG3000-Whack-a-Mole-Game-


##  Steps to Run the Sample Background
### 1. Install Pygame
```bash
python3 -m pip install pygame
```
### 2. Run the Game Background
```bash
python3 game_background.py
```
### Requirements
- Python 3.x
- Pygame
Once the program starts, a game window will open displaying the animated background.
